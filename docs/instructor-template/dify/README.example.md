# Dify / LINE 憑證範本（只放變數名稱與 placeholder）

> 這份是 **範本**。實際值請存在本機被 `.gitignore` 忽略的 `docs/instructor/dify/README.md`（或 `*.local.md`），
> **絕對不要把真實密碼、金鑰、token、IP 提交進 repo**。

```sh
# ── 老師 Dify（self-host）──
DIFY_ADMIN_INSTALL=http://<VM_IP>/install
DIFY_ADMIN_EMAIL=<ADMIN_EMAIL>
DIFY_ADMIN_NAME=admin
DIFY_ADMIN_PASSWORD=<ADMIN_PASSWORD>
DIFY_TEACHER_APP_KEY=<DIFY_APP_KEY>
ADMIN_LINE_CHANNEL_SECRET=<LINE_CHANNEL_SECRET>
ADMIN_LINE_CHANNEL_ACCESS_TOKEN=<LINE_CHANNEL_ACCESS_TOKEN>
ADMIN_LINE_PROJECT=<GCP_PROJECT_ID>

# ── 學員機（USER1 … USERn）──
DIFY_USER1_INSTALL=http://<VM_IP>/install
DIFY_USER1_EMAIL=<USER_EMAIL>
DIFY_USER1_NAME=<USER_NAME>
DIFY_USER1_PASSWORD=<USER_PASSWORD>
DIFY_USER1_APP_KEY=<DIFY_APP_KEY>
DIFY_USER1_APP_ID=<DIFY_APP_ID>
USER1_LINE_CHANNEL_SECRET=<LINE_CHANNEL_SECRET>
USER1_LINE_CHANNEL_ACCESS_TOKEN=<LINE_CHANNEL_ACCESS_TOKEN>
USER1_LINE_PROJECT=<GCP_PROJECT_ID>

# ── Dify Cloud 版（驗證用）──
DIFY_CLOUD_APP_KEY=<DIFY_APP_KEY>
CLOUD_LINE_CHANNEL_SECRET=<LINE_CHANNEL_SECRET>
CLOUD_LINE_CHANNEL_ACCESS_TOKEN=<LINE_CHANNEL_ACCESS_TOKEN>
```
